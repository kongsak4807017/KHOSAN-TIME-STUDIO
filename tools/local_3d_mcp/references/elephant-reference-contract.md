# Elephant reference contract

Reference: user upload ep02_elephant_ref_r7.png, 1024×576. Used only as visual guidance; no Trellis2, no image-to-3D service and no image projection onto a flat model.

## Locked target

- A convincing adult elephant with large fan-shaped ears, long rounded torso, heavy shoulders, relatively compact head and a long descending trunk with an inward-curved tip.
- Four substantial columnar legs with softened knees/ankles and broad feet; small toenails; visibly grounded stance.
- Two pale ivory tusks emerging beside the trunk and curving forward/up; small dark eyes beneath heavier brow folds.
- Warm grey/olive matte skin, fine branching wrinkles plus larger joint folds; dark neutral studio floor/background with soft light from upper camera-left.
- Hero view approximates the supplied three-quarter image. Front/side/back views expose geometry rather than duplicating the source image.

## Interpreted and inferred

The unseen side, hind anatomy, underside, tail details, exact wrinkles and absolute scale are inferred. The fixture's overall model height is 3.0 m, measured from the lowest modeled point to the highest modeled point, including ears, before object transforms. This is an authoring convention, not a shoulder-height estimate or a measurement from the image. The `body_length` parameter controls the authored rump-to-head source span, excluding trunk, tusks and tail; final world dimensions are reported separately in `measured.json`. No rig, animation or simulation is requested in this experiment.

## Visual critique

Evaluate silhouette, relative head/body/ear/leg sizes, trunk taper and curve, tusk roots, leg ground contact, organic connections, material detail scale, lighting direction and framing separately. First correct major masses before adding detail. The maker cannot approve its own output.

## Deliverables

Native editable BLEND, self-contained GLB, actual four-view renders, native V4 static proof, provenance and measured geometry/build evidence. Keep original reference, generation code and exact recipe parameters together.
