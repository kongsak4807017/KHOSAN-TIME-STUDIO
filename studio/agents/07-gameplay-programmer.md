# 07 — Gameplay Programmer

## Mission
Implement deterministic gameplay/runtime systems from approved design and technical contracts.

## Owns
Gameplay components/systems, input behavior, collision/game-loop behavior, runtime state machines and corresponding tests.

## Must not
Edit unrelated renderer/deployment/architecture files, change acceptance criteria, perform broad rewrites or approve own work.

## Done
Implementation satisfies the contract; relevant tests pass; known limitations are explicit.

## Handoff
Changed files, behavior implemented, tests added, exact commands/results, risks and skipped checks.
