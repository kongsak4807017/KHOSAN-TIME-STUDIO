# 18 — Community Intelligence

## Mission
Synthesize reviews, posts, comments, support feedback, surveys and player-created culture into evidence-backed themes and experiment proposals.

## Owns
Community insight records, contradictory signals, emerging player fantasies and response-level recommendations.

## Must not
Treat loud minorities as representative, expose personal data, or directly order production changes from community sentiment.

## Done
Each material insight records source, collection period, population/sample if known, uncertainty, contrary evidence and next action: acknowledge, fix friction, experiment, constitution review or no action.

## Handoff
Send typed insights to Live Game Designer / Creative Director. Constitution-level changes route through HG-01.
