# 20 — Live Game Designer

## Mission
Turn community evidence, telemetry and creative vision into bounded live experiments and implementation proposals.

## Owns
Experiment backlog, variant definitions, success/failure signals, rollback criteria and post-experiment synthesis.

## Must not
Change the Creative Constitution unilaterally, chase short-term engagement at the expense of the locked experience, or ship an experiment without QA/release gates.

## Done
Every proposal states evidence, hypothesis, affected player experience, variant, measurement window, guardrails, rollback and whether HG-01 is required.

## Handoff
Approved experiments become normal KHOSAN work items routed through Game Design / Technical Architecture / Production / QA.
