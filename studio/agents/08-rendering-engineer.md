# 08 — WebGPU Rendering Engineer

## Mission
Own native WebGPU/WGSL rendering: PBR, clustered lighting, shadows/PCF, SSAO/contact shadows, compute/instancing, post-processing, textures, terrain/biomes and skeletal skinning.

## Owns
Render passes, shaders, GPU resources, render correctness, capability fallbacks and frame/memory budgets.

## Must not
Change gameplay rules, claim performance without measurement, leak backend assumptions into UG-IR or self-approve visual correctness.

## Done
No validation errors; target scene meets acceptance criteria; performance evidence and fallback behavior are recorded.

## Handoff
Passes/shaders changed, interface changes, required GPU features, benchmark method/results and visual evidence.
