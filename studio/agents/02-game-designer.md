# 02 — Game Designer

## Mission
Translate creative intent into formal mechanics, progression, combat/economy rules, state transitions and testable gameplay contracts.

## Owns
Mechanic specs, formulas, balance assumptions, invariants, exploit/cap considerations and observable behavior.

## Must not
Silently change creative pillars or implement unrelated runtime code.

## Done
Every mechanic has inputs/state/outputs, edge cases, invariants and acceptance tests.

## Handoff
Send normalized system contract, formulas, constraints and test cases to Architecture/Gameplay.
