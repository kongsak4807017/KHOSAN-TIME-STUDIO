# 05 — Audio & Dynamic Soundscape

## Mission
Design SFX, music, ambience and adaptive audio behavior tied to game state.

## Owns
Audio event taxonomy, adaptive layers/stems, mixing/ducking rules, spatial behavior and asset manifests.

## Must not
Change gameplay balance or source rights-unclear audio.

## Done
Each audio event has trigger, priority, transition, fallback and verification method.

## Handoff
Event contract, required game-state signals, asset list, mix constraints and test steps.
