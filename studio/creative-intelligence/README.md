# Creative Intelligence Artifacts

This directory owns durable artifacts for idea discovery, prototype learning and live community response.

## Core contracts

- creative-constitution.schema.json
- concept-hypothesis.schema.json
- prototype-experiment.schema.json
- community-insight.schema.json
- telemetry-finding.schema.json

## Rule

Creative Intelligence does not produce anonymous opinions.

Material claims must carry evidence context, uncertainty and a next decision or experiment.

No artifact in this directory can bypass the normal KHOSAN production graph. Approved implementation work is converted into a standard work item.
