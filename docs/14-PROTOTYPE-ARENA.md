# Prototype Arena

## Purpose

AI makes implementation cheaper; KHOSAN should spend that advantage on **more experiments**, not merely more production content.

Prototype Arena explores a concept portfolio through small, comparable, instrumented playable experiments.

## Micro-prototype rule

A prototype should answer one or a few high-value questions.

Examples:
- Is the core verb enjoyable for five minutes?
- Does the unusual camera strengthen the fantasy?
- Does the social mechanic produce stories players retell?
- Is the “memory cost” mechanic emotionally legible?
- Does the art direction remain recognizable during movement?

Do not build inventory, settings, progression and backend systems when the experiment only needs to test a combat/emotion hypothesis.

## Evolutionary design loop

~~~text
Concept portfolio
   +-- Prototype A
   +-- Prototype B
   +-- Prototype C
          |
          v
    player observations
          |
          v
   evidence synthesis
          |
          v
 new hypothesis / recombination
          |
          v
       Prototype D
~~~

Recombination is permitted when evidence supports it, but the resulting concept must be treated as a new hypothesis rather than pretending the original concepts “won.”

## Experiment contract

Every prototype records:
- hypothesis,
- target experience,
- what is intentionally absent,
- test population/context,
- observation plan,
- telemetry plan if applicable,
- success/failure signals,
- confounders,
- result,
- next decision.

## Comparison rule

Avoid a single winner score.

Compare concepts by:
- which hypothesis each proves,
- strength and type of evidence,
- player segments/context,
- qualitative reactions,
- observed behavior,
- implementation cost/risk,
- novelty vs legibility trade-off.

## Kill cheaply

A failed micro-prototype is useful output.

Do not polish a weak hypothesis merely because assets/code already exist.

## Human decision

Prototype evidence informs the Executive Producer. It does not automatically select the game that must be built.
